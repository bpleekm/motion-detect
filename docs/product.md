# 产品定义

## 目标与使用者

面向本地视频分析作业和上层语义审核服务，快速产生可追溯的像素变化证据。场景包括固定机位、多个连续源文件，以及需要原帧复核的争议活动。

交付价值：解码不重复做逐帧分析；每个结果可以回到源文件、stream和PTS；AI只需消费小结果及按需原图。

## 职责

1. 索引全部解码帧，包括未选帧，记录源文件EOF。
2. 在真实PTS上选择分析帧，不制造固定帧率时间。
3. 顺序更新单份MOG和Motion模型，输出独立分支及低/高区域。
4. 输出可验证、可被独立项目消费的协议。

按需人物检测使用GPU推理，触发仍为非warming且低档候选存在、普通运动未通过。预处理/阈值/NMS和坐标映射独立记录；模型或GPU推理不可用时hold，不静默CPU前向。人物检测只是观测，不覆盖静止允许加速的规则。

语义保留由motion-evidence负责。人物存在不在本组件中自动变为保留；没有候选也不等于已证明没有人。

## 产品约束

- 源文件只读，源指纹在运行前验证。
- 同一作业的源文件有序处理，几何变化需明确拒绝或独立作业，不静默重置模型。
- 时长、源文件等数据缺失应hold；损坏的指纹/身份属于错误，不能伪装成完整结果。
- 所有缓存、构建和真实运行结果位于外部私有根。

## 验收

合成素材可独立完成解码→证据→消费；时间身份可复现，全部索引帧有唯一ID；完整运行有EOF与计数。空间测试覆盖4conn、面积等号、边界及低高独立性。GPU性能是单独验收项，不能用CPU主流程或历史结果代替。
