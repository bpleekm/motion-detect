# 验证方案

## 必需检查

1. 合成视频中静止、移动、亮度变化和再次静止能够完成全流程；所有原始帧被索引，完整运行EOF、选帧顺序和计数一致。
2. 对角接触保持两个4conn分区；面积等于低阈值接受、等于严格高阈值拒绝；触边与空/满输入正确。
3. 低/高形态学独立从raw生成；补padding和清水印的顺序保持。
4. 缺失源或时长hold；源SHA变化拒绝；不输出假complete。
5. motion-evidence消费独立输出，保留PTS与锁定范围。

## 原生迁移验证

先同prepared核对MOG/Motion/空间，再接GPU灰度/解码。整数像素应精确，FP32噪声验证有效阈值和实际学习闭环。诊断读回与性能严格分开，MOG跨后端差异单独量化。

性能包含初始化/解码/同步/日志/排空，记录实际后端、源码/输入指纹和资源；阶段重叠，不求和替代墙钟。旧工程的实测不自动成为新仓库的成绩。

测试输出与pytest缓存通过外部`WORK_ROOT`和`--basetemp`重定向。真实数据只读使用、报告私有保存，公开仓库仅保留合成测试和方法。

跨仓库烟测由motion-evidence的`tools/integration_smoke.py`调用检测CLI；支持CPU reference和显式native-gpu/native-build，使用合成媒体、空env和模拟Responses验证主流程，直接源文件依赖只通过版本化文件传递。
